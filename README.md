# Greenden-Tailwind Project 🌿

Greenden is a simple and responsive website created using "HTML and Tailwind CSS". This project was built to practice Tailwind CSS utility classes, responsive layouts, and clean website design.

## Pages

* Home – Introduction and main sections of the website
* Products – Displays the available products
* Contact – Contact information and a contact form

## Technologies Used

* HTML5
* Tailwind CSS

## Features

* Clean and simple user interface
* Responsive design
* Tailwind CSS utility classes
* Three-page website with easy navigation
* Mobile-friendly layout

## Purpose

This project was created as a practice project to improve my skills in "HTML, Tailwind CSS, responsive design, and website layout development".
